# Security Policy

## Supported Versions

This package is pre-`1.0`. Security fixes are made on the current published line only.

| Version | Supported |
| --- | --- |
| Current `0.x` release | Yes |
| Older `0.x` releases | No |

## Reporting A Vulnerability

Do not open a public issue for a security bug.

Use GitHub private vulnerability reporting for this repository. If it is not enabled, use the private maintainer contact listed on the npm package or repository profile.

Include:

- affected package version
- Node and Prettier versions
- a small input that shows the issue
- what impact you expect

You should get an initial response within 7 days. If the report is accepted, the fix will ship with a changelog entry and a patch release when a release is needed.
